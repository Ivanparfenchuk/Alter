# Changelog

All notable changes to Alter are documented here. This project uses date-based
versioning (`YYYY.MM.DD`).

## [2026.07.24] (build 10)

Baseline documented feature set.

### Features
- **Regex Manager**: store, folder-organize, search, and copy regular
  expressions; export/import the whole collection as a `.zip` of `JSON` files.
- **Alert Dialog Generator**: generate Smali for Rounded, Material 3, iOS, iOS
  Dark, and Expiration dialogs, with built-in `SharedPreferences` tamper
  protection.
- **Native Dumper Injection**: one-tap injection of the il2cpp dumper and dex
  dumper native libraries, with 32-bit and signing options.
- **LSParanoid Port**: obfuscate `const-string` literals in DEX classes with a
  configurable class filter.
