# Security & Responsible Use

## Intended use

Alter is a reverse-engineering and modding toolkit intended for:

- security research and education,
- analyzing and modifying applications you **own** or are **authorized** to
  modify.

You are solely responsible for how you use Alter and for complying with all
applicable laws and any third-party terms of service. Do not use it to infringe
others' rights.

## Reporting a security issue

If you discover a security vulnerability in the Alter application, please report
it privately rather than opening a public issue:

- Telegram: [t.me/AvoluxModz](https://t.me/AvoluxModz)

Please include a description of the issue, affected version, and steps to
reproduce. We'll acknowledge your report and work on a fix.

## Third-party components

Alter bundles third-party open-source components (see
[docs/THIRD_PARTY_LICENSES.md](docs/THIRD_PARTY_LICENSES.md)). Vulnerabilities in
those components are best reported upstream to their maintainers; feel free to
let us know as well so we can update.
