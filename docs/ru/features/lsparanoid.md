# Порт LSParanoid

Порт **LSParanoid** для устройства, обфусцирующий литералы `const-string` внутри
DEX-классов и усложняющий статический анализ ваших строк.

- На основе [LSPosed/LSParanoid](https://github.com/LSPosed/LSParanoid) (Apache-2.0),
  который, в свою очередь, форкнут от [MichaelRocks/paranoid](https://github.com/MichaelRocks/paranoid).

## Как пользоваться

1. Откройте **LSParanoid** на вкладке Home.
2. Нажмите **Select APK file** и выберите цель.
3. В поле **Class obfuscation configuration** опишите, какие классы обфусцировать.
   Конфигурация: по одному правилу на строку, например:

   ```
   alter.Main.*
   !com.BuildConfig
   alter.MainActivity;onCreate\(.*
   ```

   - Обычный шаблон включает подходящие классы/члены.
   - Ведущий `!` исключает шаблон.
4. При необходимости включите **Sign**, чтобы переподписать результат.
5. Нажмите **Continue**, чтобы получить обфусцированный APK.

## Примечания

- Обфускация заменяет читаемые строковые константы вызовами деобфускатора,
  строки перестают быть видны в статическом дампе.
- Она не шифрует код и не мешает инспекции в рантайме, только повышает планку
  для статического анализа строк.
