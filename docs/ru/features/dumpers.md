# Внедрение нативных дамперов

Внедряйте библиотеки анализа в рантайме одним нажатием. Alter сам подготавливает
Smali-загрузчик и размещает библиотеки, без ручного патчинга и сборочного
окружения.

## Инструменты

### il2cpp dumper
Внедряет нативную библиотеку, которая дампит метаданные IL2CPP (классы, методы,
поля) из **запущенного** Unity-приложения, целиком внутри его собственного
процесса. Полезно для анализа Unity/IL2CPP-сборок.

- На основе [muhammadrizwan87/il2cppdumper](https://github.com/muhammadrizwan87/il2cppdumper) (MIT).

### dex dumper
Внедряет нативную библиотеку, которая извлекает DEX-файлы из памяти запущенного
приложения, удобно для восстановления DEX из упакованных или защищённых
приложений.

- На основе [muhammadrizwan87/dexdumper](https://github.com/muhammadrizwan87/dexdumper) (MIT).

## Опции

- **Select APK file**: выбрать целевой APK.
- **32-bit**: включайте, если цель работает как 32-битный процесс, чтобы были
  внедрены соответствующие нативные библиотеки.
- **Sign**: переподписать пропатченный APK, чтобы его можно было установить.

## Как пользоваться

1. Откройте **Dex dumper** или **il2cpp dumper** на вкладке Home.
2. Нажмите **Select APK file** и выберите цель.
3. Задайте **32-bit** / **Sign** при необходимости.
4. Нажмите **Inject dumper**.
5. Установите и запустите пропатченное приложение; дамп будет записан в директорию
   файлов приложения (точные пути см. в соответствующих upstream-проектах).

> Эти библиотеки работают внутри собственной песочницы целевого приложения.
> Используйте их только на приложениях, которыми владеете или вправе
> анализировать.
