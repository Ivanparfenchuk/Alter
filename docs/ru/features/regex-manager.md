# Менеджер регулярок

Отдельное рабочее пространство для регулярных выражений, которыми вы пользуетесь
при моддинге. Вместо разрозненных заметок Alter даёт организованную библиотеку с
поиском, которую можно переносить между устройствами.

## Зачем нужен Alter

Alter появился из-за неудовлетворённости существующими инструментами для
регулярок в моддинг-сцене. Такие инструменты дают лишь фиксированный набор
заранее одобренных паттернов и не позволяют пользователю добавлять свои,
поэтому главная проблема так и не решается: ваши собственные паттерны всё равно
валяются как попало. Alter это ответ на такую ситуацию. Ваши регулярки
принадлежат вам: вы их добавляете, организуете и забираете с собой.

## Что умеет

- **Добавляйте свои паттерны.** Храните сколько угодно паттернов, у каждого имя
  и пара «поиск/замена». Никакого «одобренного» списка и никаких ограничений;
  библиотеку вы строите сами.
- **Группируйте по папкам.** Раскладывайте паттерны по именованным папкам под
  задачу, например `remove ads`, `anti analytics`, `safety` или `freemium`.
  Папки отображаются как фильтры-чипы вверху вкладки Regex.
- **Поиск по подтверждению.** Введите запрос и подтвердите его, чтобы запустить
  поиск. Список не перестраивается при каждом нажатии клавиши, поэтому на больших
  коллекциях прокрутка и ввод остаются плавными.
- **Копирование одним нажатием.** Копируйте любую сторону паттерна (поиск или
  замену) в буфер мгновенно.

## Бэкап и импорт

Всю коллекцию можно экспортировать и восстанавливать как переносимый архив.

- **Формат:** архив `.zip` с обычными `JSON`-файлами и одним файлом подписи.
  Архив остаётся читаемым, чтобы его могли открыть другие инструменты.

Внутри архива:

| Файл | Назначение |
| --- | --- |
| `folders_meta.json` | Индекс. Массив `JSON`, описывающий все папки коллекции: сколько их и каковы `id` и `name` каждой папки. |
| `regex_folder_<id>.json` | По одному файлу на папку, имя файла совпадает с `id` папки. Массив `JSON` с паттернами этой папки. |
| `backup.sig` | Подпись архива (хеш его содержимого). Alter использует её для проверки целостности при импорте. |

### Форматы файлов

`folders_meta.json`:

```json
[
  { "id": "1784926869621_0", "name": "remove ads" },
  { "id": "1784926869624_1", "name": "anti analytics" }
]
```

`regex_folder_<id>.json`:

```json
[
  { "name": "имя паттерна", "search": "<строка поиска>", "replace": "<строка замены>" }
]
```

### Файл подписи

`backup.sig` содержит хеш-подпись содержимого архива. Смысл в том, чтобы
структура `.zip` оставалась обычной и открывалась в других инструментах, но при
этом Alter мог убедиться, что архив не меняли вне приложения. При импорте Alter
пересчитывает подпись и сравнивает её с `backup.sig`. Если архив редактировали
вне Alter, подпись не совпадёт и приложение откажется его импортировать, что не
даёт загрузить битые или неправильные коллекции.

Для бэкапа и импорта используйте кнопку резервного копирования на вкладке Regex.

## Чем отличается

Alter выделяют две возможности, и связывает их один принцип:

1. **Можно добавлять свои паттерны.** Alter это дом для паттернов, которые
   собираете вы, а не закрытый список чужих «одобренных».
2. **Организация по папкам.** Коллекция раскладывается по именованным папкам, а
   не лежит одной кучей.
3. **Ручной бэкап и импорт.** Полный контроль над экспортом и восстановлением
   коллекции в виде переносимого архива, которым можно делиться.
