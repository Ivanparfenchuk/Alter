# Разрешения

Alter запрашивает небольшой набор разрешений, и все они связаны с чтением и
записью APK-файлов и управлением бэкапами регулярок. Приложение не собирает
аналитику и никуда не отправляет ваши данные.

| Разрешение | Имя в манифесте | Зачем нужно Alter |
| --- | --- | --- |
| Чтение общего хранилища | `android.permission.READ_EXTERNAL_STORAGE` | Читать выбранные APK-файлы и импортировать бэкапы коллекций регулярок. |
| Управление всеми файлами | `android.permission.MANAGE_EXTERNAL_STORAGE` | Доступ к APK в любом месте устройства, чтобы выбирать и патчить файлы вне scoped-директории приложения. |
| Запись в общее хранилище | `android.permission.WRITE_EXTERNAL_STORAGE` | Сохранять пропатченные APK, сгенерированные файлы и бэкапы регулярок. |
| Вибрация | `android.permission.VIBRATE` | Тактильная отдача при действиях в интерфейсе. |
| Интернет | `android.permission.INTERNET` | Проверять обновления и скачивать свежий релиз. |
| Состояние сети | `android.permission.ACCESS_NETWORK_STATE` | Определять наличие сети перед сетевыми операциями. |

## Примечания

- **Доступ к хранилищу на Android 11+.** Поскольку Alter патчит произвольные
  APK-файлы, выбранные пользователем, он использует доступ ко «всем файлам»
  (`MANAGE_EXTERNAL_STORAGE`). Выдать его можно в
  **Настройки → Приложения → Alter → Разрешения**.
- **`READ_/WRITE_EXTERNAL_STORAGE`**: устаревшие разрешения для хранилища,
  актуальны в основном для Android 10 и ниже.
- Интернет Alter использует только для проверки обновлений и скачивания, больше
  ни для чего.
