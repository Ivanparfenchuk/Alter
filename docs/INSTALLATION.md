# Installation

## Requirements

- **Android 7.0 (API 24)** or newer
- **No root** required
- Storage permission (granted on first use, see [PERMISSIONS.md](PERMISSIONS.md))

## Install the APK

1. Open the [latest release](https://github.com/Ivanparfenchuk/Alter/releases/latest).
2. Download `Alter.apk`.
3. Open the downloaded file. If prompted, allow your browser or file manager to
   install unknown apps:
   **Settings → Apps → Special access → Install unknown apps**.
4. Confirm the install.

## Permanent "latest" link

This link always points to the newest release's APK, so you can bookmark or
share it:

```
https://github.com/Ivanparfenchuk/Alter/releases/latest/download/Alter.apk
```

## Updating

Alter can check for updates from within the app. You can also revisit the
Releases page or the permanent link above at any time to grab the newest build.

## Uninstall

**Settings → Apps → Alter → Uninstall.** Your exported regex backups (`.zip`
files you saved to storage) are kept and are not removed by uninstalling.
