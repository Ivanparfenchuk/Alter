# Contributing to Alter

Thanks for your interest in Alter! The application itself is closed-source, so
code contributions to the app are not accepted, but there are still several
valuable ways to help.

## Ways to contribute

### Report bugs
Found something broken? Open a
[bug report](https://github.com/Ivanparfenchuk/Alter/issues/new/choose) and
include your Alter version, device model, Android version, the tool you used,
and clear reproduction steps.

### Request features
Have an idea? Open a
[feature request](https://github.com/Ivanparfenchuk/Alter/issues/new/choose) and
describe the problem you're trying to solve, not just the solution.

### Share regex collections & dialog templates
Alter is more useful with good building blocks. You're welcome to share regex
collections (exported `.zip` backups) or dialog setups with the community via
the [project channel](https://t.me/AlterProject).

### Improve the documentation
This repository's docs are fair game for pull requests: fix typos, clarify
steps, or improve examples under `docs/`.

### Help test
Try new releases on different devices and Android versions and report what works
and what doesn't.

## Ground rules

- Be respectful and constructive.
- Use Alter responsibly and only on apps you own or are authorized to modify.
  See [SECURITY.md](SECURITY.md).
- One issue per report; search existing issues first to avoid duplicates.
